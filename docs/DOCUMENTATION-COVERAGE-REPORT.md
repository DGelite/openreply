## 2. Authentication & Architectural Families

BoxAPI is partitioned into two completely independent API families with distinct authorization mechanisms and network profiles:

### Family A: Official Instagram Messaging API (Meta Partner Wrapper)
* **Base URL:** `https://boxapi.ir`
* **Auth Method:** Header `X-Api-Key: <YOUR_API_KEY>`
* **Account Identifier:** UUID `account_id` (representing the connected Instagram Business/Creator page).
* **Webhook Signature:**
  ```
  X-BoxApi-Signature = "sha256=" + HMAC_SHA256("{timestamp}.{raw_body}", webhook_secret)
  X-BoxApi-Timestamp = "{timestamp}"
  ```
* **Payload Serialization:** JSON (`Content-Type: application/json`).

### Family B: Public Data & Scraping API (High-Concurrency Mirror)
* **Base URL:** `https://boxapi.ir/api/instagram/`
* **Auth Method:** Header `Authorization: Bearer <YOUR_API_TOKEN>`
* **Account Identifier:** Numeric Instagram User ID (`id`) or Username (`username`).
* **Request Pattern:** All endpoints are `POST` with JSON bodies (except `GET /api/my`).
